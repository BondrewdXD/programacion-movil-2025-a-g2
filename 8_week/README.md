# 🛠️ Taller Colaborativo: Desarrollo de Componentes en Ionic

## 📌 Descripción
En este taller, los estudiantes trabajarán en equipos de tres personas para comprender y aplicar la temática de componentes en el desarrollo móvil con Ionic. El enfoque será práctico y orientado a la socialización del conocimiento, combinando teoría y aplicación con una presentación breve y un ejemplo funcional. 

Cada equipo será asignado o elegirá un framework adicional a Ionic (Angular, React o Vue) para contextualizar su explicación.

## 🎯 Objetivo
Al finalizar la sesión, cada grupo habrá desarrollado un componente reutilizable basado en la entidad **"Persona"**, que pueda adaptarse a diferentes contextos como el registro de un cliente, proveedor, empleado u otro caso propuesto por el equipo.

- **9:20 - 10:20 →** Socialización de resultados de manera aleatoria entre los equipos.

## 📌 Tareas a Realizar

### 🔍 Investigar y socializar
- ¿Qué es un componente?
- ¿Para qué sirve?
- ¿Cómo se usa en el framework asignado (Angular, React o Vue con Ionic)?
- ¿Cuándo no es recomendable usarlo?

### 💡 Elegir un caso de uso
- **Caso propuesto:** Componente **Persona** con campos básicos:
  - Nombre, Apellido, Documento, Fecha de Nacimiento, Dirección, Teléfono, Correo, etc.
  - Reutilizable para distintos tipos de usuarios (cliente, empleado, proveedor...)
- Alternativamente, pueden proponer otro caso práctico si el equipo lo desea.

### 🏗️ Diseñar y desarrollar
- Un **componente funcional** con el framework asignado.
- Código debe permitir **reutilización** y separación de **lógica y presentación**.
- Adaptar el componente a **al menos dos escenarios de uso distintos** (ej. cliente y proveedor).

### 🎤 Preparar presentación
- **Diapositivas** con una breve explicación teórica (**5 minutos**).
- **Demostración** del código fuente y del componente en funcionamiento.

### 🗣️ Socializar en clase
- Exposición aleatoria de cada equipo.
- Compartir pantalla, explicar concepto y mostrar funcionamiento.
- **Entregar material en un repositorio** (GitHub, GitLab, Drive, etc.)

## 📌 Reglas y Recomendaciones

✅ **Equipos de 3 personas como máximo.**
✅ Deben entregar y socializar:
  - **Presentación explicativa** (PDF, PPT o HTML).
