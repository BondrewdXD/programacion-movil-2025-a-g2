# 🧩 Ejercicio Propuesto: Gestión de Personal en un Centro Médico

## 📌 Descripción  
En este ejercicio, los estudiantes desarrollarán un componente reutilizable enfocado en la **gestión de personal médico**, utilizando Ionic en conjunto con un framework adicional (Angular, React o Vue). El objetivo es aplicar los conceptos de componentes para construir interfaces organizadas, reutilizables y funcionales dentro de un contexto realista: un sistema de gestión para un centro médico.

El componente central será una **card** con formulario que permita registrar, modificar, eliminar y consultar personal médico, adaptándose a distintos roles del sistema.

## 🎯 Objetivo  
Desarrollar un componente central llamado **"Gestión de Personal Médico"**, reutilizando elementos previamente creados (inputs, botones, layouts, etc.) y adaptándolo a diferentes pantallas según el tipo de usuario (Médico, Enfermero, Recepcionista, Paciente), incluyendo campos comunes y específicos por rol.

## 📌 Instrucciones Generales  

### 🛠️ Construcción del Componente

Desarrollar una **card funcional** que contenga:  
- Título del layout: **"Gestión de Personal Médico"**  
- Campos base:
  - Nombre  
  - Apellido  
  - Edad  
  - Correo electrónico  
- Botones funcionales:
  - Agregar  
  - Modificar  
  - Eliminar  
  - Consultar  

### 🧑‍⚕️ Diseñar las siguientes pantallas (una por rol):  
- Médico  
- Enfermero  
- Recepcionista  
- Paciente  

> **Nota:** Reutilizar los componentes previamente creados (inputs personalizados, botón, layout base, etc.)

### ➕ Campos Adicionales por Rol  

| Rol           | Campos Adicionales Sugeridos                     |
|---------------|--------------------------------------------------|
| Médico        | Especialidad, Número de licencia médica          |
| Enfermero     | Turno asignado, Área de atención                 |
| Recepcionista | Horario laboral, Extensión telefónica            |
| Paciente      | Número de historia clínica, Tipo de afiliación   |
