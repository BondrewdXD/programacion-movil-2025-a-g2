# Semana 7 - Inicio segundo corte

## Resumen de la semana
Se nos fue enviado un archivo con la configuración de descarga de los siguientes programas:
- **Node.js**
- **Ionic**

Con el objetivo de empezar a afianzar nuestros conocimientos en este nuevo lenguaje de desarrollo.
Por consiguiente, se nos pidió que creáramos una cuenta en **Ionic** para poder vincularla con nuestra cuenta personal de **GitHub**.
Después de eso, estuvimos en una reunión para afianzar esa práctica y dar un abrebocas de cómo unir dos modificaciones en la misma rama de **GitHub** mediante un **merge** desde el navegador. 
Se nos indicó la nueva rama para próximas clases: **develop**, la cual contendrá el código tanto de **backend** como de **frontend** de cada **HU** que hemos creado alrededor del corte 1.

## Tareas realizadas

- **Instalación de Node.js e Ionic**:
  - Se descargaron e instalaron las herramientas necesarias para comenzar el desarrollo.
  - Se realizaron pruebas para verificar el correcto funcionamiento de ambas herramientas.

- **Creación de cuenta en Ionic**:
  - Se creó una cuenta en la plataforma de Ionic.
  - Se vinculó la cuenta de Ionic con GitHub para futuros despliegues y configuraciones.

- **Reunión de introducción a Ionic y GitHub**:
  - Se explicaron conceptos básicos de Ionic y su estructura.
  - Se mostró cómo realizar un **merge** de dos modificaciones en la misma rama desde el navegador de GitHub.

- **Nueva estructura de ramas en GitHub**:
  - Se estableció la rama **develop** como base para próximas clases.
  - Se explicó que esta rama contendrá el código tanto de **backend** como de **frontend** de cada **HU** del primer corte.

## Posibles planes para la siguiente semana
- Profundizar en el uso de Ionic y su integración con proyectos reales.
- Crear la primera aplicación utilizando **Ionic Framework**.
- Implementar conexión entre el frontend y backend dentro de la rama **develop**.
- Subir avances al repositorio y realizar pruebas de funcionalidad.
