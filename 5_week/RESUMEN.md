# Semana 5 - Inicio del alistamiento de una aplicación móvil

## Resumen de la semana
Esta semana se nos propuso trabajar en un ejercicio centrado en una problemática en un aeropuerto, la cual describe que existe "Falta de un sistema móvil que permita a los pasajeros, personal de aeropuertos y tripulación acceder a información en tiempo real. Actualmente depende de sistemas desactualizados y canales de comunicación fragmentados, lo que genera demoras, desinformación y una mala experiencia para los usuarios."

A partir de esta problemática, se nos brindó un documento con las Historias de Usuario (HU) que debemos aplicar en el proyecto. Las HU presentadas son:
- **HU1: Comprensión del Problema**
- **HU2: UI/UX Base**
- **HU3: Primer Layout Funcional en Figma**

Además, se nos dio la tarea de subir un avance a nuestro GitHub con las siguientes especificaciones:
1. Crear una rama `feature/exam-c1`.
2. Subir un archivo `exam-links.txt` con los siguientes enlaces:
   - Enlace público de Trello con las tres HU documentadas.
   - Enlace público de Figma con el diseño de HU3.
   - Enlace del repositorio en Git.
3. Subir los cambios y adjuntar el archivo en Moodle.
4. Descargar y adjuntar en Moodle el soporte correspondiente.

## Tareas realizadas
- Estudio de la problemática del aeropuerto y análisis de las necesidades de un sistema móvil para la gestión de vuelos.
- Se documentaron las tres historias de usuario (HU) en el tablero de Trello:
  - **HU1: Comprensión del Problema**: Identificar y comprender la problemática para la creación de la aplicación.
  - **HU2: UI/UX Base**: Definir la base de diseño para la interfaz de usuario y experiencia de usuario de la aplicación.
  - **HU3: Primer Layout Funcional en Figma**: Diseño del primer layout funcional de la aplicación en Figma.
- Subida del avance a GitHub:
  - Se creó la rama `feature/exam-c1`.
  - Se subió el archivo `exam-links.txt` con los enlaces solicitados.
  - Se realizaron los cambios necesarios y se adjuntaron en Moodle.

## Posibles planes para la siguiente semana
- Continuar trabajando en el diseño y desarrollo de la aplicación móvil, enfocándose en mejorar la interfaz y la experiencia del usuario.
- Reflejar las actualizaciones del diseño en **Figma** y continuar iterando sobre el layout.
- Reforzar la comprensión de las funcionalidades necesarias para el sistema móvil en el aeropuerto, con el objetivo de mejorar la interacción entre pasajeros, personal y tripulación.
- Preparar la siguiente entrega de avances en el repositorio de GitHub y en Moodle.
