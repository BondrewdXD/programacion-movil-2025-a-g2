# 🍽️ Aplicación: Sistema de Gestión de Reservas para Restaurante en Ionic

## 📌 Descripción  
En este proyecto, los estudiantes desarrollarán una **aplicación completa en Ionic** (Angular, React o Vue) que permita gestionar reservas en un restaurante. La aplicación debe incluir **componentes reutilizables**, una **pantalla principal integrada**, y un **backend funcional** con operaciones completas sobre las reservas. Además, se evaluará el uso adecuado de **control de versiones** y la presentación de un **video explicativo**.

## 🎯 Objetivo  
Implementar una solución integral que abarque:
- Creación de **componentes reutilizables**.
- **Integración de componentes** en una pantalla principal.
- Desarrollo de un **backend funcional** con documentación.
- Uso profesional de **Git y control de versiones**.
- Generación de **material audiovisual** y documentación técnica del proyecto.

## ⏰ Cronograma sugerido  
- Semana 1 → Desarrollo de componentes y pantalla principal.  
- Semana 2 → Backend, integración, control de versiones y documentación.  
- Fecha de entrega: según plataforma Moodle.
---

## 🧩 Componentes Reutilizables  

Desarrollar los siguientes tres componentes de forma modular, clara y reutilizable:

1. **Selección de Fecha y Hora**  
   - Permite al usuario elegir día y hora de la reserva.

2. **Ingreso de Datos del Cliente**  
   - Campos: nombre, teléfono de contacto, correo electrónico, etc.

3. **Selección de Mesa**  
   - Mostrar las mesas disponibles y permitir escoger una.
---

## 🧑‍💻 Pantalla Principal: Gestión de Reservas  

Crear una vista principal llamada **"Gestión de Reservas"** que integre los tres componentes anteriores, facilitando la creación de reservas en una sola vista. Esta debe ser intuitiva, funcional y visualmente clara.
---

## 🔧 Backend Funcional  

- Desarrollar una **API REST** con operaciones CRUD sobre las reservas.  
- Debe gestionar: **fecha/hora**, **cliente**, **mesa**.  
- Documentar la API utilizando **Swagger**.  
- Probar los endpoints con Swagger u otra herramienta como Postman.

---
