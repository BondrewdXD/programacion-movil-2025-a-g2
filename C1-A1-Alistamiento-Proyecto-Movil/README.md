# Inicio del alistamiento de una aplicación móvil

1. Crear una rama `feature/exam-c1`.
2. Subir un archivo `exam-links.txt` con los siguientes enlaces:
   - Enlace público de Trello con las tres HU documentadas.
   [Trello - Aplicación Móvil para la Gestión y Control de Vuelos](https://trello.com/invite/b/67c70e844e03b404ecfba1ec/ATTI4d658229c7c90d6433a1da07d42e048d7DD070AE/aplicacion-movil-para-la-gestion-y-control-de-vuelos)
   - Enlace público de Figma con el diseño de HU3.
   [Figma - Layout Funcional Aplicación Móvil para la Gestión y Control de Vuelos](https://www.figma.com/design/dMX86EDavpzB7PAgCQkFbm/APP_NEKOSKY?node-id=0-1&t=QvJiNIaQFXfqaBqh-1)
   - Enlace del repositorio en Git.
   [Github - Enlace repositorio](https://github.com/BondrewdXD/programacion-movil-2025-a-g2)
3. Subir los cambios y adjuntar el archivo en Moodle.
4. Descargar y adjuntar en Moodle el soporte correspondiente.
