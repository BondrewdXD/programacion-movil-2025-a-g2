# 🚀 Unidad 3: Desarrollo Avanzado y Proyecto Final

## 📌 Descripción  
Durante esta etapa final del curso, los estudiantes deberán consolidar todos los conocimientos adquiridos para desarrollar una aplicación móvil funcional que resuelva un problema específico. Este proyecto final incluirá tanto el desarrollo avanzado del frontend y backend, como la aplicación de principios de diseño, arquitectura, optimización, testing y control de versiones.  

Además, se presentará de forma profesional mediante una **APK funcional**, **video demostrativo**, **repositorio con control de versiones**, **backlog con evidencias** y una **documentación completa** del sistema.

---

## 🎯 Objetivos

- Aplicar conceptos avanzados de desarrollo móvil usando Ionic (Angular, React o Vue).
- Utilizar plugins y componentes avanzados para mejorar la experiencia de usuario.
- Consolidar backend funcional y conectividad con el frontend.
- Realizar pruebas de funcionalidad y optimización de la aplicación.
- Documentar y sustentar adecuadamente el proceso de desarrollo.
- Realizar la entrega final del **Parcial Corte 3** y presentación del **proyecto completo**.

---

## 📱 Requerimientos del Proyecto Final

### 🧠 Funcionalidad
- La aplicación debe resolver un problema real o simulado.
- Implementar un CRUD completo y funcional.
- Asegurar conectividad con backend y uso eficiente de recursos.
- Garantizar trazabilidad mediante backlog y control de versiones.

### ⚙️ Desarrollo Avanzado
- Uso de **pantallas interactivas** y **UX optimizada**.
- Implementación de **componentes avanzados** y **plugins nativos**.
- Pruebas funcionales básicas para garantizar calidad y estabilidad.
- Consolidación de todo el sistema en la rama final `feature/project`.

---

## 📦 Entregables

1. 🎥 **Video corto (60 segundos)** explicando el propósito de la aplicación y su funcionalidad.
2. 📱 **Archivo APK funcional**, con enlace público de descarga.
3. 🔗 **Repositorio Git**, con:
   - Control de versiones por historia (`feature/HU-*`)
   - Rama final `feature/project` completamente funcional.
4. 📊 **Presentación técnica** del proyecto.
5. 📌 **Backlog completo** con evidencias (capturas y enlace a tablero digital como Trello, Notion o Jira).
6. 🧩 **Prototipo visual** (Figma, Adobe XD u otro).
7. 📄 **Documentación completa**, incluyendo:
   - Requerimientos del sistema.
   - Arquitectura general (capas, tecnologías).
   - Diagramas: UML, MER (Modelo Entidad-Relación), MR (Modelo Relacional).
   - Manual de usuario.

---

## 🗣️ Sustentación Final

- La presentación será **grupal**.
- Cada equipo deberá:
  - Explicar el problema abordado.
  - Mostrar el flujo funcional de la app.
  - Defender las decisiones técnicas tomadas.
  - Demostrar la integración de todas las fases del desarrollo.
- Se evaluará:
  - **Diseño visual y experiencia de usuario**.
  - **Calidad del código y arquitectura técnica**.
  - **Coherencia entre prototipo, backlog, código y documentación**.

---

## ✅ Recomendaciones

- Verificar que todo el contenido entregado esté actualizado y funcional.
- Mantener una estructura limpia y clara del repositorio.
- Cumplir con los tiempos establecidos para la entrega y sustentación.
- Leer cuidadosamente las **especificaciones detalladas en el documento adjunto en la plataforma**.
