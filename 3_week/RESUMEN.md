# Semana 3 - Explicación ¿Qué es una Historia de Usuario (HU)?

## Resumen de la semana
En esta semana, nos enfocamos en la explicación y comprensión de lo que es una **Historia de Usuario (HU)**, un concepto fundamental para el desarrollo ágil. Se nos presentó **Trello** como herramienta para llevar el registro de las historias de usuario para el proyecto. También, se nos explicó cómo estructurar las HU en un tablero y qué partes son esenciales para una gestión eficaz.

## Tareas realizadas
- Configuración de un tablero en **Trello** para registrar nuestras historias de usuario (HU).
- Se nos indicó la estructura de los estados esenciales para definir un buen HU en el tablero:
  - `In process`: Cuando la historia está en desarrollo.
  - `Completed`: Cuando la historia ha sido completada.
  - `Please review`: Cuando la historia está lista para ser revisada.
  - `Approved`: Cuando la historia ha sido aprobada.
- Se realizó un ejemplo práctico con la **gestión de ventas de un supermercado** (Carrito de Compras) para entender cómo se organiza una historia de usuario en un tablero.
- Como tarea, se nos solicitó empezar a desarrollar nuestras propias **historias de usuario** para el proyecto y documentarlas en nuestro tablero de **Trello**.

## Posibles planes para la siguiente semana

- Empezar a vincular las historias de usuario con las funcionalidades del proyecto y asignar tareas específicas.
- Asegurarse de tener claras las prioridades de las historias y las dependencias entre ellas.
