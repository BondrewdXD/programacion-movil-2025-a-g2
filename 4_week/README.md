# Semana 4 - Revisión de Historias de Usuario

## Resumen de la semana
En esta semana, se revisaron las **Historias de Usuario (HU)** y se nos proporcionó una estructura base que debe tener cada historia dentro de nuestro tablero de **Trello**. La HU estuvo basada en el ejemplo de un sistema de gestión de ventas de un supermercado (Carrito de Compras), el cual vimos en la semana 3. Además, se nos propuso un ejercicio práctico en el que tuvimos que realizar un **mockup** de la HU, y se nos presentó una nueva herramienta para crear estos mockups: **Figma**.

## Tareas realizadas
- Se nos dio la estructura base para escribir una historia de usuario (HU), la cual debe contener:
  - **Descripción**: Detalla el papel del usuario y sus necesidades.
  - **Criterios de Aceptación**: Define las funcionalidades y validaciones que deben cumplirse para aceptar la historia.
  - **Criterios de Finalización**: Establece las condiciones necesarias para dar por terminada la historia de usuario.
  
  Ejemplo de una historia de usuario completa:
  - **Descripción**:
    - Como administrador del sistema, quiero registrar, actualizar, eliminar y consultar categorías de productos, para gestionar eficientemente la organización de los productos dentro del sistema.
  - **Criterios de Aceptación**:
    - Registro, Edición, Eliminación y Consulta de Categorías, con detalles como campos obligatorios, validaciones, y acciones posibles.
  - **Criterios de Finalización**:
    - Funcionalidad desarrollada y probada, revisión de código, demostración al Product Owner y documentación actualizada.
  
- **Ejercicio práctico**: Realización de un **mockup** para la historia de usuario del "Carrito de Compras". Se nos dio libertad para diseñar el mockup de la interfaz, el cual fue revisado durante la clase.

- Se nos introdujo a **Figma**, una herramienta que utilizaremos para diseñar los mockups de nuestras aplicaciones. Se abordará más a fondo la próxima semana.
